Voxel engine · Phase 0

The world is generated.
The world then lives.

NEXORA is a voxel sandbox engine written in Rust with zero external dependencies and unsafe_code = "forbid". The engine foundation is implemented, tested and runnable.

Read this before you download. There is no renderer and no window yet — that is the state of the project, not a packaging mistake. What you get is three command-line programs. The engine builds a world, simulates it, saves it, reopens it and tells you whether it survived. You watch that happen in a terminal.

What is in the archive

nexora-headless
The vertical slice. Builds a world from a seed, generates chunks across a worker pool, edits voxels, drops a character and simulates it until it settles, streams an observer away and back, advances the clock, saves, shuts down, reopens and verifies every probe.
nexora-benchmark
The measurement harness behind the published baseline. Run it on your own machine — the numbers in the repository are from one box and say so.
nexora-texture-forge
The procedural material generator. Reads the material definitions bundled in the archive and writes PBR maps that are reproducible from their own record.

Plus the content the forge reads, and both licences. Every binary was run on its own platform by the workflow that built it, before it was packaged.

Build it from source

Rust 1.85 or newer, and nothing else — the engine crates pull in no external dependencies at all. 

git clone https://github.com/Lucas-Belucci-Bellini/NEXORA
cd NEXORA

cargo test --workspace          # the full test suite
cargo run -p nexora-headless    # the vertical slice, verified end to end
cargo run -p nexora-benchmark -- --markdown
