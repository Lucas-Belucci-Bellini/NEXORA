## Objetivo

Mapear a documentação do projeto e distinguir documentos de arquitetura, sistemas, engenharia, decisões e governança.

## Hierarquia de autoridade

```text
NEXORA MASTER ARCHITECTURE
        ↓
ARCHITECTURE / ENGINEERING RULES
        ↓
SYSTEM SPECIFICATIONS
        ↓
IMPLEMENTATION DOCS
        ↓
EXPERIMENTS / NOTES
```

Em conflito, um documento inferior não substitui silenciosamente uma regra superior.
