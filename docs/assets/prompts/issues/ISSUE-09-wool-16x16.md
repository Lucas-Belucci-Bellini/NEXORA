# NEXORA — LÃS 16×16 / PROMPTS PRONTOS

As 240 variantes devem ser produzidas por combinações controladas de cor + tom + variação. O prompt abaixo já pode ser copiado; altere somente a identificação da variante indicada na linha.

## Prompt-base pronto
```text
Create an original 16×16 pixel-art wool texture for the NEXORA voxel game.
Soft woven-fiber appearance translated into crisp pixel clusters, readable at tiny resolution, consistent pixel density, restrained detail, coherent color hierarchy and seamless repeat.
Color family: [COLOR FAMILY]
Tone: [LIGHT / MID / DARK]
Variant: [VARIANT]
Invent the exact pixel arrangement from scratch.
Do not copy, trace, reconstruct or closely imitate any existing game's wool texture, palette structure or pixel pattern.
No text, logo, watermark, perspective, environment or UI.
Output exactly one 16×16 square texture.
```

## 240 variantes
Use as families: vermelho, vermelho-escuro, vermelho-claro; laranja, laranja-escuro, laranja-claro; amarelo, amarelo-escuro, amarelo-claro; verde, verde-escuro, verde-claro; ciano, ciano-escuro, ciano-claro; azul, azul-escuro, azul-claro; violeta, violeta-escuro, violeta-claro; magenta, magenta-escuro, magenta-claro; rosa, rosa-escuro, rosa-claro; marrom, marrom-escuro, marrom-claro; bege, bege-escuro, bege-claro; cinza, cinza-escuro, cinza-claro; branco, preto; além de famílias minerais, desaturadas, terrosas e tons especiais.

Para fechar exatamente 240, usar 24 famílias cromáticas × 10 variações controladas. A diferença entre variantes deve ser principalmente cromática e de pequenas alterações de fibra, sem criar 240 estilos desconexos.

## Regra
Não gerar 240 prompts gigantes duplicados. Cada combinação final deve usar o prompt-base com os valores concretos da variante catalogada.

## Aceitação
- [ ] 240 combinações catalogadas
- [ ] exatamente 16×16
- [ ] mesma linguagem visual
- [ ] cores distinguíveis
- [ ] sem cópia deliberada
- [ ] proveniência registrada
