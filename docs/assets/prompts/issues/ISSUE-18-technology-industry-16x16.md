# NEXORA — TECNOLOGIA E INDÚSTRIA / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar.

## Prompt 01 — Máquina Industrial
```text
Create an original 16×16 pixel-art industrial machine surface for NEXORA. Heavy engineered metal, compact mechanical details, restrained highlights and visible wear. Design for voxel factories and repeatable modules. Invent every pixel arrangement from scratch. Do not copy or closely imitate any existing game's machine texture, model surface, logo or pattern. No text, watermark, perspective or scenery.
```
## Prompt 02 — Componente Eletrônico
```text
Create an original 16×16 pixel-art electronic component texture for NEXORA. Small conductive tracks, dark substrate, tiny metallic contacts and controlled contrast. Keep it readable at very low resolution. Invent a new arrangement and do not reproduce any existing game asset or board layout. No text, logos, watermark or environment.
```
## Prompt 03 — Circuito
```text
Create an original 16×16 pixel-art circuit-board texture for NEXORA. Dense but readable conductive paths, geometric junctions, dark substrate and subtle metallic highlights. Completely original routing and pixel pattern. Do not imitate real branded boards or existing game textures. No readable text, logo or watermark.
```

```

```
