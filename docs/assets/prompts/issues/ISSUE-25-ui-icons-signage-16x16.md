# NEXORA — UI, ÍCONES E SINALIZAÇÃO / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar.

## Prompt 01 — Ícone de Inventário
```text
Create an original 16×16 pixel-art inventory icon for the NEXORA game. Strong silhouette, extremely clear low-resolution readability, restrained palette and consistent pixel density. Design the symbol from scratch and do not imitate any existing game icon, logo or UI. No text, watermark or unnecessary background.
```
## Prompt 02 — Ícone de Ferramenta
```text
Create an original 16×16 pixel-art tool icon for NEXORA. Clear silhouette, one dominant functional feature, controlled highlights and consistent pixel clusters. Invent the exact design independently. Do not copy any existing game's tool icon or visual arrangement. No text, logo or watermark.
```
## Prompt 03 — Ícone de Material
```text
Create an original 16×16 pixel-art material icon for NEXORA. Compact readable shape, distinctive material cues and limited palette. Invent a unique symbol and pixel arrangement. Do not reproduce existing game item icons, textures or logos. No text or watermark.
```
## Prompt 04 — Ícone de Status
```text
Create an original 16×16 pixel-art status icon for NEXORA. Use a simple abstract visual symbol that communicates a game state at tiny resolution. Completely original geometry and pixel placement. Do not copy existing game HUD symbols. No text, logo or watermark.
```
## Prompt 05 — Marcador
```text
Create an original 16×16 pixel-art world marker for NEXORA. Strong simple silhouette, clear directional or positional meaning and restrained palette. Invent the marker language from scratch. Do not imitate existing map markers or game UI. No text or logo.
```
## Prompt 06 — Indicador
```text
Create an original 16×16 pixel-art system indicator for NEXORA. Use simple geometric pixel clusters and a distinct shape language for warning, active or inactive states. No readable text. Invent all iconography independently. Do not copy existing game's indicators.
```
## Prompt 07 — Símbolo de Cidade
```text
Create an original 16×16 pixel-art fictional city symbol for NEXORA. Memorable silhouette, simple geometry and distinctive invented identity. Do not use real flags, coats of arms, logos or existing game symbols. No text or watermark.
```
## Prompt 08 — Símbolo de Facção
```text
Create an original 16×16 pixel-art fictional faction symbol for NEXORA. Strong iconic silhouette, limited palette and a simple invented motif reflecting a fictional group's character. Do not copy any real or existing game emblem. No text, logo or watermark.
```
## Prompt 09 — Sinalização Mundial
```text
Create an original 16×16 pixel-art world signage symbol for NEXORA. Clear universal-style symbol with geometric simplicity and strong contrast. Do not reproduce real-world traffic signs, logos or existing game signs. Invent the visual language from scratch. No readable text.
```
## Prompt 10 — Placa Gráfica
```text
Create an original 16×16 pixel-art graphic sign for NEXORA. Fictional pictogram, strong silhouette and compact information design suitable for the voxel world. No real logos, copied signs or readable text. Completely original pixel arrangement.
```
## Prompt 11 — Mapa Estilizado
```text
Create an original 16×16 pixel-art abstract map symbol for NEXORA. Use invented terrain marks, paths and location notation rather than real cartography. Very clear at tiny resolution. Do not copy any game's map iconography or real map design. No readable text.
```
## Prompt 12 — Marcador de Exploração
```text
Create an original 16×16 pixel-art exploration marker for NEXORA. Distinctive fictional shape, readable at tiny size and compatible with a larger map language. Invent the symbol from scratch. No copying existing games, logos or UI symbols.
```
## Prompt 13 — Símbolo de Sistema
```text
Create an original 16×16 pixel-art system symbol for NEXORA. Minimal geometric construction, strong semantic silhouette and coherent pixel density. Completely original iconography. Do not imitate any existing software or game interface. No text, logo or watermark.
```

## Aceitação
- [ ] 16×16
- [ ] símbolos legíveis
- [ ] sem copiar ícones/flags/logos
- [ ] integração em HUD e mundo validada
- [ ] proveniência registrada
