# NEXORA — VIDROS 16×16 / PROMPTS PRONTOS

Todos os prompts são prontos para copiar/colar. Vidro deve manter leitura de transparência em baixa resolução e padrão original.

## Prompt 01 — Vidro claro
```text
Create an original 16×16 pixel-art clear glass texture for the NEXORA voxel game. Use sparse cyan-gray reflection pixels, subtle frame-neutral transparency cues and clean empty areas. The pattern must be original and suitable for repeated windows. Do not copy existing game glass textures. No text, logo or watermark.
```
