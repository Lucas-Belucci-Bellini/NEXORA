# NEXORA — TEXTURE PIPELINE / FASE 1

## Objetivo
Fechar a primeira geração visual do NEXORA em **16×16**, com prompts individuais prontos para copiar/colar.

As issues específicas #5–#13 tratam das famílias iniciais. As issues #15–#26 tratam das famílias descobertas posteriormente. A #28 trata das armaduras especiais dos personagens da Baluarte.

## Regra de produção
```text
CATÁLOGO
↓
VERIFICAR SE JÁ EXISTE
↓
COPIAR O PROMPT INDIVIDUAL DA ISSUE
↓
NANO BANANA / FERRAMENTA DE GERAÇÃO
↓
SELEÇÃO
↓
CLEANUP
↓
VALIDAÇÃO 16×16
↓
PROVENIÊNCIA
↓
IMPORT / TESTE NO NEXORA
```

## Regra de resolução
**2026 / primeira geração → 16×16.**

Não criar 32×32, 64×64, normal map, roughness, height ou PBR para preencher esta fase. Essas são gerações visuais futuras.

## Regra de originalidade
Os prompts devem usar conceitos de material, função, natureza, arquitetura ou tema como inspiração, mas **não reproduzir textura, pixel arrangement, silhueta, paleta estruturada, logo, símbolo, personagem, modelo, skin, interface ou asset específico de outra obra**.

Não escrever prompts como “faça igual a Minecraft” ou usar screenshots de terceiros como referência para reconstrução.

## Prompt de segurança/originalidade comum
```text
Create a completely original NEXORA asset from the material or concept described below.
Use only the broad concept as inspiration.
Invent the exact pixel arrangement, cluster placement, proportions, palette relationships, surface pattern and visual signature from scratch.
Do not copy, trace, reconstruct, closely imitate, or reproduce any existing game asset, texture, icon, model, skin, logo, symbol, interface, or recognizable visual design.
The result must have an independent NEXORA visual identity.
Resolution: exactly 16×16 pixels.
No text, watermark, third-party logo, copied symbol, or accidental background.
```

## Proveniência mínima
Para assets gerados, registrar quando possível:
```text
asset_id
prompt
ferramenta/modelo
data de geração
arquivo original
arquivo final
hash
commit
status de integração
```
