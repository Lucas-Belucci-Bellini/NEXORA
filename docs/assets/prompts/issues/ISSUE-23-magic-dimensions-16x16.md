# NEXORA — MAGIA, DIMENSÕES E MATERIAIS ESPECIAIS / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar.

## Prompt 01 — Material Mágico
```text
Create an original 16×16 pixel-art magical material texture for the NEXORA universe. Use a fictional mineral or organic material with controlled unusual coloration, crisp pixel clusters and subtle energy cues. Make it readable and reusable as a construction material. Invent every pixel arrangement from scratch. Do not imitate existing fantasy-game materials. No text, logo, watermark or scene.
```
## Prompt 02 — Cristal Especial
```text
Create an original 16×16 pixel-art special crystal texture for NEXORA. Faceted mineral clusters, distinctive fictional coloration and restrained internal glow represented only with pixels. Completely original shape language and surface pattern. Do not reproduce existing game crystals. No text, logo, watermark or environment.
```
## Prompt 03 — Runa Original
```text
Create an original 16×16 pixel-art fictional rune texture for NEXORA. Design a brand-new geometric symbol with simple readable strokes and restrained energy accents. Do not copy real alphabets, religious symbols, logos or existing game runes. No readable text, watermark or scenery.
```
## Prompt 04 — Artefato
```text
Create an original 16×16 pixel-art fictional artifact material for NEXORA. Ancient engineered or magical object surface with a memorable compact silhouette and subtle unusual details. Invent the object and pixel arrangement completely. Do not imitate existing fantasy-game artifacts. No text, logo or watermark.
```
## Prompt 05 — Bloco Mágico
```text
Create an original 16×16 pixel-art magical construction block for NEXORA. Dense supernatural mineral surface, restrained glow pixels, coherent repeatable clusters and strong material identity. Invent a unique visual language rather than copying any existing game block. No text, logos, watermark or scenery.
```
## Prompt 06 — Material Dimensional
```text
Create an original 16×16 pixel-art dimensional material texture for NEXORA. Use impossible-looking but controlled mineral structures, fractured geometry and a distinctive fictional palette. Keep the material readable and seamless. Do not imitate any existing dimensional block or game texture. No text or watermark.
```
## Prompt 07 — Material Espacial
```text
Create an original 16×16 pixel-art space-resource material for NEXORA. Dark cosmic mineral or engineered alloy with subtle unusual inclusions and a controlled sci-fi palette. Highly readable at tiny resolution. Invent the pattern from scratch and do not copy existing games. No text, logo or watermark.
```
## Prompt 08 — Energia Condensada
```text
Create an original 16×16 pixel-art condensed-energy material for NEXORA. Compact abstract energy structure expressed as crisp luminous pixel clusters on a controlled base material. Original color arrangement and shape language only. No copied sci-fi game effect, text, logo or watermark.
```
## Prompt 09 — Tecnologia de Endgame
```text
Create an original 16×16 pixel-art endgame technology material for NEXORA. Advanced fictional alloy with precise structural segmentation and restrained energy accents, readable at tiny resolution. Invent all surface details independently. Do not imitate any existing game's endgame block or machine. No text or logo.
```
## Prompt 10 — Recurso Extremamente Raro
```text
Create an original 16×16 pixel-art ultra-rare resource for the NEXORA universe. Distinctive mineral composition, memorable palette, compact high-contrast pixel clusters and subtle supernatural or advanced-tech cues. Completely original design. No copied game asset, logo, text or watermark.
```

## Aceitação
- [ ] 16×16
- [ ] símbolos originais
- [ ] sem referência visual direta a franquias
- [ ] materiais testados no jogo
- [ ] proveniência registrada
