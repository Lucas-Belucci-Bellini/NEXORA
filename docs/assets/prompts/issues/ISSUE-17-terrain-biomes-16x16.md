# NEXORA — TEXTURES 16×16 / TERRENO, SOLO E BIOMAS

Todos os prompts são prontos para copiar/colar.

## Prompt 01 — Terra Seca
```text
Create an original 16×16 pixel-art dry soil texture for the NEXORA voxel game. Use warm earthy tones, compact irregular soil clusters, subtle cracks and natural variation. Make it seamless and highly reusable in terrain generation. Invent the pixel arrangement from scratch. Do not copy or closely imitate any existing game's terrain texture. No text, logo, watermark, scenery or perspective.
```
## Prompt 02 — Terra Úmida
```text
Create an original 16×16 pixel-art moist soil texture for NEXORA. Darker earth tones, compact damp clusters and subtle organic variation. Keep it readable at tiny resolution and suitable for seamless terrain. Create a unique pixel structure unrelated to existing game textures. No text, logo, watermark or scenery.
```
