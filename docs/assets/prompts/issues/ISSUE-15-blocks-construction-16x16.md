# NEXORA — TEXTURES 16×16 / BLOCOS E CONSTRUÇÃO

## Regra
Todos os prompts abaixo são independentes e prontos para copiar/colar. Gerar somente 16×16 nesta geração.

## Prompt 01 — Tijolo NEXORA
```text
Create an original 16×16 pixel-art brick construction texture for the NEXORA voxel game. Use irregular handmade bricks, varied warm mineral tones, subtle mortar gaps and controlled weathering. Make it highly repeatable and useful for large buildings. Invent a completely new pixel arrangement. Do not copy, trace, reconstruct or closely imitate any existing game's brick texture, palette structure or pixel clusters. No text, logo, watermark, perspective or scenery.
```

## Prompt 02 — Concreto NEXORA
```text
Create an original 16×16 pixel-art concrete block texture for NEXORA. Dense fine aggregate, subtle tonal variation, small pores and restrained industrial wear. Strong readable material identity and seamless repetition. Invent a new surface pattern unrelated to existing game textures. Do not copy any recognizable texture arrangement, palette relationship or pixel design from another game. No text, logo, watermark, perspective or environment.
```

## Prompt 03 — Cimento NEXORA
```text
Create an original 16×16 pixel-art cement surface texture for NEXORA. Pale mineral grey, slightly powdery surface, uneven curing marks and very subtle aggregate variation. Keep it simple enough to tile across walls and floors. The pixel structure must be independently designed and must not reproduce an existing game texture. No text, logo, watermark, scenery or perspective.
```

## Prompt 04 — Pedra Trabalhada
```text
Create an original 16×16 pixel-art worked-stone construction texture for NEXORA. Use carefully cut stone faces with irregular seams, restrained chiseling marks and a coherent natural palette. Designed for castles, foundations and civic architecture. Create entirely new pixel clusters and seam placement. Do not imitate any existing game's blocks or recognizable texture patterns. No text, logo, watermark or environment.
```

## Prompt 05 — Ladrilho
```text
Create an original 16×16 pixel-art tile texture for NEXORA. Small ceramic or stone tiles arranged in a distinctive geometric layout, with controlled variation, subtle grout and believable wear. Construction-friendly and seamless. Do not reproduce any existing game's tile pattern, palette organization or pixel arrangement. No text, logo, watermark, perspective or scenery.
```

## Prompt 06 — Azulejo
```text
Create an original 16×16 pixel-art glazed ceramic wall tile texture for NEXORA. Use a restrained invented motif made from simple geometric shapes, subtle glaze variation and small imperfections. The motif must be completely fictional and original. Do not imitate real logos, historical emblems or existing game tiles. No readable text, watermark, perspective or scenery.
```

## Prompt 07 — Telha
```text
Create an original 16×16 pixel-art roof tile texture for NEXORA. Layered fired-clay roof tiles, warm mineral colors, slight edge variation and controlled weathering. Make the pattern repeat naturally across rooftops. Invent all pixel clusters independently. Do not copy an existing game's roof tile texture or recognizable design. No text, logo, watermark or environment.
```

## Prompt 08 — Metal Estrutural
```text
Create an original 16×16 pixel-art structural metal texture for NEXORA. Dark industrial alloy with subtle brushed variation, reinforced sections and restrained wear. Designed for beams, frames and heavy construction. Use a completely original pixel arrangement and tonal hierarchy. Do not imitate any existing game's metal texture. No text, logo, watermark, perspective or scenery.
```

## Prompt 09 — Chapa Metálica
```text
Create an original 16×16 pixel-art metal sheet texture for NEXORA. Flat industrial sheet metal with subtle panel seams, small scratches and controlled oxidation. Highly repeatable and readable at low resolution. Invent a unique pattern rather than copying any game asset. No text, logos, watermark, perspective or environment.
```

## Prompt 10 — Viga
```text
Create an original 16×16 pixel-art structural beam surface for NEXORA. Heavy alloy beam texture with longitudinal wear, small fastener hints and subdued industrial contrast. The texture must remain useful across modular structures. Do not reproduce any existing game's beam or block texture. No text, logo, watermark or scenery.
```

## Prompt 11 — Cabo/Conduto
```text
Create an original 16×16 pixel-art industrial conduit texture for NEXORA. Dark insulated tubing with subtle bands, connector cues and controlled wear. Designed as a modular surface/segment texture. Invent the pixel structure independently and do not copy existing game assets. No text, logo, watermark, perspective or environment.
```

## Prompt 12 — Bloco Decorativo
```text
Create an original 16×16 pixel-art decorative construction block for NEXORA. Use a refined but simple ornamental material pattern that remains readable and repeatable at tiny resolution. It must feel native to NEXORA rather than any existing game. Do not copy motifs, logos, symbols or recognizable block textures. No text, watermark, perspective or scenery.
```

## Prompt 13 — Piso
```text
Create an original 16×16 pixel-art flooring texture for NEXORA. Durable construction flooring with a clear modular rhythm, subtle wear and believable surface variation. Designed for large interiors and exterior platforms. Invent a new pixel pattern and do not imitate any existing game floor texture. No text, logo, watermark or environment.
```

## Prompt 14 — Parede Especial
```text
Create an original 16×16 pixel-art special wall material for NEXORA. Dense engineered wall surface with unique panel divisions, seams and restrained wear. It must work in repeated architectural modules. Create the design from scratch without copying any existing game texture or pattern. No text, logo, watermark, perspective or environment.
```

- [ ] tiling validado
- [ ] catálogo e proveniência registrados
- [ ] integração no jogo validada
