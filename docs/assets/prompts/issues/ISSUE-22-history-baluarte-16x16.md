# NEXORA — HISTÓRIA, ARQUIVOS E CRÔNICAS DA BALUARTE / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar. A arte deve ser original do NEXORA; referências narrativas podem inspirar função, mas não copiar designs.

## Prompt 01 — Arquivo Físico
```text
Create an original 16×16 pixel-art historical archive object texture for the NEXORA universe. Use aged paper, wood or metal details, compact readable pixel clusters and believable archival wear. Make it feel like a physical piece of world history without reproducing any real archive or game asset. No readable text, logos or watermark.
```
## Prompt 02 — Documento Visual
```text
Create an original 16×16 pixel-art fictional historical document texture for NEXORA. Show abstract marks, diagrams and paper aging without readable real-world language. Invent the graphic layout from scratch. Do not copy real documents or existing game assets. No logos, watermark or recognizable third-party symbols.
```
## Prompt 03 — Mapa
```text
Create an original 16×16 pixel-art fictional world map texture for NEXORA. Use invented coastlines, terrain marks, route lines and symbols, designed to be readable at tiny resolution. Do not reproduce real maps, franchises, existing game maps or recognizable cartographic layouts. No real-world text or logos.
```
## Prompt 04 — Placa Histórica
```text
Create an original 16×16 pixel-art fictional historical sign for NEXORA. Strong silhouette, aged material, simple abstract markings and an invented symbolic language. No readable real-world text, real logos or copied game signage. Completely original composition.
```
## Prompt 05 — Selo/Símbolo
```text
Create an original 16×16 pixel-art fictional seal or emblem for the NEXORA universe. Simple geometric or organic symbolism, memorable silhouette and restrained palette. Invent a brand-new symbol. Do not copy real heraldry, logos, flags or existing game emblems. No text or watermark.
```
## Prompt 06 — Inscrição
```text
Create an original 16×16 pixel-art fictional inscription texture for NEXORA. Use abstract invented glyph-like marks that are not copied from real alphabets or existing fictional franchises. Aged stone or metal surface, high readability and sparse detail. No readable real text, logo or watermark.
```
## Prompt 07 — Livro/Volume
```text
Create an original 16×16 pixel-art historical book or archive volume texture for NEXORA. Aged cover, compact spine details and subtle wear, with no readable title. Distinctive fictional visual language. Do not imitate existing game books or real publications. No text, logo or watermark.
```
## Prompt 08 — Caixa Histórica
```text
Create an original 16×16 pixel-art historical storage crate for NEXORA. Wood or metal construction, reinforced corners, faded surface and archaeological wear. Invent the markings and pixel pattern. No real-world logos or copied game crates. No readable text or watermark.
```
## Prompt 09 — Objeto Arqueológico
```text
Create an original 16×16 pixel-art archaeological artifact texture for NEXORA. Fictional object with aged stone, ceramic or metal surface, subtle damage and distinctive shape. It must communicate historical value without copying a real artifact or existing game object. No text or logo.
```
## Prompt 10 — Relíquia
```text
Create an original 16×16 pixel-art fictional relic texture for NEXORA. Ancient material, restrained unusual detail, compact silhouette and subtle signs of age. Make it unique to the NEXORA universe and do not imitate existing fantasy-game relics. No text, logo or watermark.
```
## Prompt 11 — Equipamento Abandonado
```text
Create an original 16×16 pixel-art abandoned technology surface for NEXORA. Weathered alloy, corrosion, broken seals and age cues, designed to look like historical evidence rather than a new machine. Completely original pixel arrangement. No copied game asset, logo or text.
```
## Prompt 12 — Ruína Histórica
```text
Create an original 16×16 pixel-art ruined historical material for NEXORA. Broken masonry, worn stone or metal, discoloration and layered age. Designed as visual evidence of a past civilization. Do not copy any existing game's ruin texture. No text, logo or watermark.
```
## Prompt 13 — Instalação Antiga
```text
Create an original 16×16 pixel-art ancient installation surface for NEXORA. Weathered engineered material, faded panels, corrosion and traces of obsolete technology. Invent the pattern independently. No copied science-fiction or game facility textures. No readable text or logo.
```
## Prompt 14 — Evidência Física
```text
Create an original 16×16 pixel-art physical evidence object for the NEXORA historical evidence system. Use a fictional material, visible provenance cues through wear and damage, and a clear low-resolution silhouette. Do not copy real artifacts or existing game assets. No text, logo or watermark.
```

## Aceitação
- [ ] 16×16
- [ ] símbolos e mapas totalmente originais
- [ ] sem texto real obrigatório
- [ ] integração ao sistema de evidências
- [ ] proveniência registrada
