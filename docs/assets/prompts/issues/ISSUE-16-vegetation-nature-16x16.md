# NEXORA — TEXTURES 16×16 / VEGETAÇÃO E NATUREZA

Todos os prompts são prontos para copiar/colar.

## Prompt 01 — Folhas
```text
Create an original 16×16 pixel-art leaf texture for the NEXORA voxel game. Use clustered organic pixels, varied greens, subtle light-dark grouping and a distinctive botanical structure. Make it readable and reusable in voxel foliage. Invent a completely new pixel arrangement. Do not copy or closely imitate any existing game's leaf texture. No text, logo, watermark, scenery or perspective.
```
## Prompt 02 — Tronco Especial
```text
Create an original 16×16 pixel-art special tree trunk texture for NEXORA. Use irregular bark strips, layered brown tones, small natural scars and strong vertical growth direction. Seamless and construction-friendly. Create an entirely new pixel structure; do not reproduce any existing game texture. No text, logo, watermark or environment.
```
## Prompt 03 — Arbusto
```text
Create an original 16×16 pixel-art bush texture for NEXORA. Dense rounded vegetation translated into crisp pixel clusters, with layered green tones and subtle natural variation. Readable at tiny resolution and suitable for repeated world generation. Do not imitate existing game foliage. No text, logo, watermark or scenery.
```
## Prompt 04 — Flores
```text
Create an original 16×16 pixel-art flowering plant texture for NEXORA. Use a simple original blossom shape, compact pixel clusters and a contrasting botanical palette. Make the species visually distinct without relying on tiny details. Do not copy real-world logos, game assets or recognizable existing plant designs. No text or watermark.
```
## Prompt 05 — Planta Pequena
```text
Create an original 16×16 pixel-art small ground plant for NEXORA. Crisp organic pixel clusters, simple stem and leaf structure, restrained colors and clear biome identity. Invent the species and pixel arrangement from scratch. Do not imitate any existing game's vegetation. No text, logo, watermark or environment.
```
## Prompt 06 — Gramínea
```text
Create an original 16×16 pixel-art grass texture for NEXORA. Use several blade groups represented as strong diagonal and vertical pixel clusters, with subtle tonal variation. Designed for repeated terrain foliage. Completely original pixel placement; do not reproduce another game's grass texture. No text, logo, watermark or scenery.
```
## Prompt 07 — Musgo
```text
Create an original 16×16 pixel-art moss texture for NEXORA. Irregular organic patches, soft green mineral variation and small clumped growth translated into crisp pixels. Suitable as a surface material and overlay. Do not imitate any existing game texture or pattern. No text, logo, watermark or environment.
```
## Prompt 08 — Fungo
```text
Create an original 16×16 pixel-art fungal growth texture for NEXORA. Invent a fictional fungus with unusual cap shapes, earthy tones and compact organic clusters. Readable at 16×16 and visually distinct from common game mushrooms. Do not copy any existing asset. No text, logo, watermark or scenery.
```
## Prompt 09 — Raiz
```text
Create an original 16×16 pixel-art exposed root texture for NEXORA. Interlocking fibrous forms, dark earth tones and subtle lighter wood fibers. Suitable for terrain edges and forest structures. Invent the pattern independently; do not imitate existing game roots. No text, logo, watermark or perspective.
```
## Prompt 10 — Cultura Agrícola
```text
Create an original 16×16 pixel-art crop texture for NEXORA. Show a compact mature agricultural plant with readable leaves or grain clusters, coherent growth structure and an original color palette. Designed for repeated farmland use. Do not copy any existing game crop texture. No text, logo, watermark or environment.
```
## Prompt 11 — Fruto
```text
Create an original 16×16 pixel-art fictional fruit texture for NEXORA. Use a distinctive silhouette, memorable color grouping and small controlled pixel highlights. The fruit must be original and suitable for inventory/world use. Do not reproduce an existing game's item or fruit. No text, logo or watermark.
```
## Prompt 12 — Vegetação de Pântano
```text
Create an original 16×16 pixel-art swamp vegetation texture for NEXORA. Dark humid greens, muted organic tones, tangled compact growth and slight water-wear cues. Designed for low-resolution readability and repeated biome generation. Invent a new pattern without copying existing game vegetation. No text, logo, watermark or scenery.
```
## Prompt 13 — Vegetação de Tundra
```text
Create an original 16×16 pixel-art cold-climate vegetation texture for NEXORA. Short hardy leaves, muted green-gray tones and frost-resistant forms, clearly readable at tiny resolution. Completely original pixel placement. Do not imitate existing game foliage. No text, logo, watermark or environment.
```
## Prompt 14 — Vegetação Árida
```text
Create an original 16×16 pixel-art arid-climate plant texture for NEXORA. Compact drought-adapted structure, dusty green and brown palette, strong silhouette and sparse but meaningful pixel clusters. Invent a fictional species and unique arrangement. Do not copy existing game plants. No text, logo, watermark or scenery.
```
## Prompt 15 — Vegetação Extrema
```text
Create an original 16×16 pixel-art extreme-environment plant for NEXORA. Fictional biology, unusual but believable structure, controlled high-contrast palette and strong low-resolution silhouette. This must feel unique to NEXORA. Do not imitate any existing game's creature or plant design. No text, logo, watermark or environment.
```
## Prompt 16 — Semente
```text
Create an original 16×16 pixel-art seed texture for NEXORA. Small organic form with a highly readable silhouette, natural material variation and clear separation from other seeds. Invent the object from scratch. Do not copy existing game item art. No text, logo or watermark.
```
