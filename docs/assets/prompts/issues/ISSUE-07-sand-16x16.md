# NEXORA — AREIAS 16×16 / PROMPTS PRONTOS

## Prompts 01–24
Cada prompt pode ser copiado diretamente. Todos exigem textura exata 16×16, superfície repetível e desenho original.

### 01 — Areia de quartzo clara
```text
Create an original 16×16 pixel-art pale quartz sand texture for the NEXORA voxel game. Fine bright grains, subtle warm-cool mineral variation, irregular pixel clusters and seamless repetition. Invent the surface completely from scratch. Do not imitate any existing game texture. No text, logo, watermark or scenery.
```

