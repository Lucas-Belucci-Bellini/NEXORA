# NEXORA — ARMADURAS ESPECIAIS / PERSONAGENS DA BALUARTE

## Objetivo
Criar uma linha especial de armaduras 16×16 nomeadas em homenagem aos personagens das equipes da fanfic **Crônicas da Baluarte**.

A armadura deve ser um **design original do NEXORA**, usando somente características amplas do personagem como inspiração: função, personalidade, clima visual, materiais, papel narrativo e paleta geral.

## Regra de originalidade
Não reproduzir a roupa, armadura, capacete, logo, símbolo, arma ou silhueta específica do personagem original. Não copiar screenshots, artes oficiais, skins ou texturas de outras obras. O personagem fornece apenas inspiração temática; o resultado precisa ser uma armadura nova do universo NEXORA.

## Formato
Cada item seguirá:

`ARMADURA — [PERSONAGEM]`

16×16 como textura-base na primeira geração.

## Prompt mestre individual
```text
Create an ORIGINAL 16×16 pixel-art wearable armor texture for the NEXORA game, named ARMOR — [CHARACTER NAME].

Use only broad thematic inspiration from this fictional character's role, personality, combat identity, technological or fantastical concept, and general color mood.

Do NOT reproduce the character's original costume, armor, helmet, weapon, logo, emblem, exact silhouette, recognizable markings, or signature visual arrangement from any existing franchise.
Do not trace, reconstruct, imitate, or closely match existing character art or game skins.

Design a completely new NEXORA armor system with its own silhouette language, panel layout, materials, pixel clusters, proportions, surface wear and visual identity.

Character inspiration: [CHARACTER NAME]
Team/role inspiration: [TEAM OR ROLE]
Thematic traits: [TRAITS]
Material language: [MATERIALS]
Color mood: [PALETTE MOOD]
Armor condition: [NEW / USED / WEATHERED]
Technology/fantasy level: [INDUSTRIAL / ADVANCED / EXTREME / ARCANE]

Style:
- crisp 16×16 pixel art
- strong readable material separation
- controlled pixel clusters
- suitable for voxel character equipment
- coherent NEXORA visual language
- original surface pattern
- readable at tiny resolution

No text, watermark, third-party logo, copied symbol, exact franchise costume or recognizable replica.
```
