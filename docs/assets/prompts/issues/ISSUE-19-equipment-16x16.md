# NEXORA — EQUIPAMENTOS RESTANTES / PROMPTS PRONTOS

## Não recriar
Armaduras, armas, escudos e mesas de trabalho existentes ficam preservados. Também verificar #13 antes de gerar.

## Prompt 01 — Mochila de Exploração
```text
Create an original 16×16 pixel-art exploration backpack texture for the NEXORA voxel game. Compact rugged pack, layered fabric panels, utility pockets and restrained wear. Make it readable at tiny resolution and distinct from existing game equipment. Invent all pixel placement from scratch. No copied asset, logo, text, watermark or character scene.
```
## Prompt 02 — Equipamento de Exploração
```text
Create an original 16×16 pixel-art exploration equipment texture for NEXORA. Fictional field gear combining compact tools, straps and protective materials, with clear low-resolution silhouette. Create a completely new visual design and pixel arrangement. Do not imitate any existing game equipment. No text, logo, watermark or scenery.
```
## Prompt 03 — Equipamento Industrial
```text
Create an original 16×16 pixel-art industrial wearable equipment texture for NEXORA. Heavy protective composite, reinforced sections, utility connectors and controlled grime. Designed for workers around machines and factories. Invent a unique pattern; do not copy existing games or branded equipment. No text, logo or watermark.
```
## Prompt 04 — Equipamento Científico
```text
Create an original 16×16 pixel-art scientific field equipment texture for NEXORA. Compact fictional instrument housing, sensor modules and protective casing represented with clear pixel clusters. Advanced but readable. No real brand markings, no copied game assets, no text or watermark.
```
## Prompt 05 — Equipamento Médico
```text
Create an original 16×16 pixel-art medical support equipment texture for NEXORA. Fictional compact medical device with clean casing, diagnostic indicators and protective materials. Strong functional silhouette, low-resolution readability and original pixel arrangement. No real logos, readable text, copied game design or watermark.
```
## Prompt 06 — Suporte Ambiental
```text
Create an original 16×16 pixel-art environmental support equipment texture for NEXORA. Compact respirator, filter housing or survival module represented with simple crisp pixels, technical material separation and restrained wear. Invent the design from scratch. No copied equipment, logo, text or watermark.
```
## Prompt 07 — Ferramenta Especial
```text
Create an original 16×16 pixel-art fictional special-purpose tool for NEXORA. Strong compact silhouette, functional mechanical head, durable handle and distinctive material palette. Invent an entirely original object rather than reproducing any real or game-specific tool. No text, logo or watermark.
```
## Prompt 08 — Capacete Adicional
```text
Create an original 16×16 pixel-art protective helmet texture for NEXORA. Distinctive silhouette, layered composite material, subtle visor housing and controlled wear. This must be a new design not present elsewhere in NEXORA. Do not imitate existing game helmets or character designs. No text, logo or watermark.
```
## Prompt 09 — Tecido Técnico
```text
Create an original 16×16 pixel-art technical fabric texture for NEXORA. Tight woven pattern translated into crisp pixel clusters, durable synthetic appearance and restrained tonal variation. Seamless when appropriate. Do not copy any existing game's fabric texture. No text, logo or watermark.
```
## Prompt 10 — Material Protetivo
```text
Create an original 16×16 pixel-art protective composite material for NEXORA. Layered polymer-ceramic appearance, compact structural fibers and subtle wear. Designed for equipment and protective systems. Completely original pixel structure; no copying existing game materials. No text, logo, watermark or scenery.
```
