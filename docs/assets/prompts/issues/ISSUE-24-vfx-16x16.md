# NEXORA — VFX 16×16 / PROMPTS PRONTOS

Cada prompt abaixo pode ser copiado diretamente para geração. Para partículas, produzir fundo transparente ou transparente-ready.

## Prompt 01 — Fogo
```text
Create an original 16×16 pixel-art fire effect for the NEXORA game. Compact irregular flame silhouette, layered warm pixels, controlled bright core and darker outer edge. Designed as an animation frame, not a scene. Invent the flame shape independently. Do not imitate any existing game's fire sprite. No text, logo, watermark or baked environment.
```
## Prompt 02 — Fumaça
```text
Create an original 16×16 pixel-art smoke effect for NEXORA. Soft irregular plume represented by clustered gray pixels, varied density and a distinctive drifting silhouette. Designed for animation frames with transparent background. Do not copy any existing game's smoke sprite. No text, logo or scenery.
```
## Prompt 03 — Poeira
```text
Create an original 16×16 pixel-art dust particle effect for NEXORA. Small dispersed earthy clusters with clear motion direction and multiple density levels. Transparent-ready and suitable for animated terrain particles. Invent the arrangement from scratch. No copied game sprite, text or watermark.
```
## Prompt 04 — Faísca
```text
Create an original 16×16 pixel-art spark effect for NEXORA. Sharp compact branching pixel strokes, bright center and controlled secondary particles. Transparent-ready and designed for animation. Completely original shape and pixel arrangement. No imitation of existing game effects.
```
## Prompt 05 — Impacto
```text
Create an original 16×16 pixel-art impact effect for NEXORA. Radial compact pixel burst with varied fragments and clear directional energy. Designed as a transparent animation frame. Do not reproduce any existing game's impact sprite. No text, logo or watermark.
```
## Prompt 06 — Detritos
```text
Create an original 16×16 pixel-art debris effect for NEXORA. Several small irregular fragments with varied scale and motion cues, transparent-ready for animation. Invent a unique composition. Do not copy existing game particle sprites.
```
## Prompt 07 — Partícula Ambiental
```text
Create an original 16×16 pixel-art environmental particle effect for NEXORA. Tiny organic or mineral particles arranged for subtle animated atmospheric use. Transparent-ready, restrained palette and clear motion cue. Completely original pattern. No copied game effect.
```
## Prompt 08 — Energia
```text
Create an original 16×16 pixel-art energy effect for NEXORA. Abstract compact energy arcs and clustered pixels, readable at tiny resolution and suitable for animation. Invent an original color and shape language. Do not imitate existing science-fiction game effects. No text or watermark.
```
## Prompt 09 — Efeito Mágico
```text
Create an original 16×16 pixel-art magical effect for NEXORA. Fictional energy motif using crisp pixel clusters, subtle glow cues and an invented shape language. Transparent-ready and animation-friendly. Do not copy existing fantasy-game spell effects or symbols. No text, logo or watermark.
```
## Prompt 10 — Vapor
```text
Create an original 16×16 pixel-art steam or vapor effect for NEXORA. Compact translucent-looking clusters with a rising directional silhouette and restrained grayscale palette. Transparent-ready for animation. Invent the pattern independently; do not imitate existing game effects.
```
## Prompt 11 — Cinza
```text
Create an original 16×16 pixel-art ash particle effect for NEXORA. Tiny irregular dark and gray particles with a subtle upward or drifting motion. Transparent-ready and suited for fire/volcanic systems. Completely original particle placement.
```
## Prompt 12 — Dano de Material
```text
Create an original 16×16 pixel-art material-damage effect for NEXORA. Cracks, chips or fracture cues represented as a compact reusable overlay, with transparent-ready background. Invent the crack pattern from scratch. Do not copy any existing game's damage texture. No text, logo or watermark.
```

## Aceitação
- [ ] 16×16
- [ ] transparent-ready quando aplicável
- [ ] famílias de frames coerentes
- [ ] animações testadas
- [ ] integração validada
- [ ] proveniência registrada
