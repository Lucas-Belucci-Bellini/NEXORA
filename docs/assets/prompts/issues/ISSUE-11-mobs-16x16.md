# NEXORA — MOBS 16×16 / PROMPTS PRONTOS

A textura é somente a camada visual. Modelo, animação, comportamento, sons e IA pertencem aos sistemas próprios.

## Prompt-base pronto
```text
Create an original 16×16 pixel-art texture concept for a NEXORA voxel creature.
Design a completely original creature identity using only the broad biological/ecological concept below. Invent the exact color distribution, pixel clusters and markings from scratch.
The texture must support a future creature model and remain readable at tiny resolution.
Do not copy, trace, reconstruct or closely imitate any existing game's creature, skin, mob texture, character or visual signature.
Creature family: [FAMILY]
Species concept: [SPECIES]
Biome: [BIOME]
Role: [PASSIVE / NEUTRAL / HOSTILE / SPECIAL]
Palette mood: [PALETTE]
No text, logo, watermark, copied symbol, UI or environment.
Output exactly one 16×16 texture concept.
```

## Catálogo de 600
Organizar em famílias antes da geração: terrestres, aquáticos, aéreos, subterrâneos, artrópodes, répteis, mamíferos, aves, anfíbios, seres vegetais, criaturas extremas, criaturas dimensionais, criaturas espaciais e entidades especiais. Dentro de cada família, variar espécie, biome, comportamento visual, porte e paleta.

## Regra de produção
Não inventar 600 criaturas sem relação. Criar famílias visuais reutilizáveis, mas garantir que cada espécie tenha identidade própria.

## Regra de originalidade
Não usar “faça igual a [personagem/jogo]”. Referências ecológicas ou funcionais podem existir, mas a aparência deve nascer do design NEXORA.

## Aceitação
- [ ] 600 entradas catalogadas
- [ ] prompt aplicado a cada família/espécie
- [ ] 16×16 quando aplicável
- [ ] textura compatível com futuros modelos
- [ ] nenhuma cópia deliberada
- [ ] proveniência registrada
