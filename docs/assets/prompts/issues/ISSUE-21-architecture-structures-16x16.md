# NEXORA — ARQUITETURA E ESTRUTURAS / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar.

## Prompt 01 — Porta
```text
Create an original 16×16 pixel-art architectural door material for the NEXORA voxel game. Strong readable panel structure, durable material, subtle hinges or seams and controlled wear. Designed for modular buildings. Invent a completely new pixel arrangement. Do not copy any existing game's door texture or recognizable design. No text, logo, watermark or scenery.
```
## Prompt 02 — Janela
```text
Create an original 16×16 pixel-art architectural window material for NEXORA. Distinctive frame, simple glass area, subtle reflection cues and coherent construction palette. Designed for modular walls. Do not imitate existing game windows or interfaces. No text, logo or watermark.
```
## Prompt 03 — Portão
```text
Create an original 16×16 pixel-art industrial gate texture for NEXORA. Heavy segmented metal, reinforced joints and restrained weathering. Suitable for large entrances. Create the pixel structure from scratch; no copying existing games or real-world brands. No text, logo or watermark.
```
## Prompt 04 — Escada
```text
Create an original 16×16 pixel-art stair material for NEXORA. Durable stone, metal or composite steps with clear repeating geometry and subtle wear. Designed for modular construction. Invent a new pixel pattern and do not reproduce an existing game's stair texture.
```
## Prompt 05 — Piso Especial
```text
Create an original 16×16 pixel-art special architectural flooring texture for NEXORA. Distinctive modular pattern, strong material identity and controlled wear. Useful for civic, industrial or scientific interiors. Completely original pixel arrangement. No copied game texture, logo, text or watermark.
```
## Prompt 06 — Parede Modular
```text
Create an original 16×16 pixel-art modular wall material for NEXORA. Repeating structural sections, subtle seams and balanced tonal variation, suitable for large buildings. Invent the surface from scratch and do not imitate any existing game's block pattern. No text or logo.
```
## Prompt 07 — Coluna
```text
Create an original 16×16 pixel-art structural column surface for NEXORA. Dense engineered material with vertical segmentation, restrained wear and readable construction logic. Designed for modular architecture. No copying existing game textures or visual designs.
```
## Prompt 08 — Torre
```text
Create an original 16×16 pixel-art tower structure surface for NEXORA. Heavy masonry or alloy with modular paneling and subtle weathering, designed for repeated vertical architecture. Invent all pixel clusters independently. No copied game texture.
```
## Prompt 09 — Ponte
```text
Create an original 16×16 pixel-art bridge structural material for NEXORA. Reinforced stone, metal or composite with clear load-bearing segmentation and controlled wear. Modular and construction-friendly. Do not imitate existing games or real branded structures.
```
## Prompt 10 — Grade
```text
Create an original 16×16 pixel-art metal grate material for NEXORA. Repeating openings, industrial alloy, dark recesses and subtle oxidation. High readability at tiny resolution. Invent a new geometry and pixel arrangement. No copying existing game grates.
```
## Prompt 11 — Cerca
```text
Create an original 16×16 pixel-art fence material for NEXORA. Modular posts and narrow structural elements represented clearly in crisp pixels, with controlled wear. Do not copy existing game fences or recognizable patterns. No text, logo or watermark.
```
## Prompt 12 — Telhado Especial
```text
Create an original 16×16 pixel-art advanced roof surface for NEXORA. Modular overlapping panels or tiles, coherent weathering and distinct architectural identity. Invent a new pattern without reproducing existing game roofs. No text or logo.
```
## Prompt 13 — Instalação Industrial
```text
Create an original 16×16 pixel-art industrial facility surface for NEXORA. Heavy engineered panels, vents, supports and restrained grime, suitable for large modular factories. Completely original pixel structure. No copied game architecture, text or logos.
```
## Prompt 14 — Instalação Científica
```text
Create an original 16×16 pixel-art scientific facility material for NEXORA. Clean technical composite panels, subtle seams and restrained advanced details, designed for modular laboratories. Invent the visual language from scratch. No copied game textures, brands, text or watermark.
```
## Prompt 15 — Instalação Militar / Bunker / Ruína
```text
Create an original 16×16 pixel-art fortified structure material for NEXORA. Heavy defensive concrete or alloy, modular seams, weathering, damage and age. Suitable for military bases, bunkers and abandoned ruins. Create an entirely original surface pattern. Do not copy any existing game's bunker or ruined-block texture. No text, logo or watermark.
```
