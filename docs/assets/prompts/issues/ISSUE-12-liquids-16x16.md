# NEXORA — LÍQUIDOS 16×16 / PROMPTS PRONTOS

Cada prompt é independente e pode ser copiado diretamente. A textura é a base visual; animação e simulação pertencem ao sistema de líquidos.

## Prompt 01 — Água doce
```text
Create an original 16×16 pixel-art freshwater liquid texture for the NEXORA voxel game. Use a restrained blue-cyan palette, sparse wave cues and transparent-looking depth through clustered pixels. Seamless and animation-friendly. Invent the exact pixel pattern from scratch. Do not copy any existing game liquid texture. No text, logo, watermark or scenery.
```
## Prompt 02 — Água salgada
```text
Create an original 16×16 pixel-art seawater texture for NEXORA. Slightly deeper blue-green palette, compact wave clusters and subtle mineral variation. Seamless, readable and original. No copied game pattern.
```
## Prompt 03 — Água turva
```text
Create an original 16×16 pixel-art muddy water texture for NEXORA. Brown-green translucent-looking clusters, reduced clarity and subtle sediment patterns. Invent the pixel arrangement independently.
```
## Prompt 04 — Água gelada
```text
Create an original 16×16 pixel-art icy water texture for NEXORA. Cool blue-gray transparent-looking surface with sparse frost cues and low-resolution readability. Completely original.
```
## Prompt 05 — Lava
```text
Create an original 16×16 pixel-art volcanic lava texture for NEXORA. Dark molten base with controlled orange-red luminous clusters, uneven flow rhythm and strong material identity. Designed for animation and seamless tiling. Do not imitate existing game lava textures.
```
## Prompt 06 — Óleo
```text
Create an original 16×16 pixel-art industrial oil texture for NEXORA. Very dark fluid with subtle warm reflective bands and dense smooth pixel grouping. Original pattern, no copied game texture.
```
## Prompt 07 — Combustível
```text
Create an original 16×16 pixel-art fictional fuel liquid texture for NEXORA. Deep amber-green industrial liquid with compact reflective highlights and controlled opacity cues. Invent a new surface pattern.
```
## Prompt 08 — Produto químico
```text
Create an original 16×16 pixel-art fictional chemical liquid texture for NEXORA. Unusual but coherent cyan-green coloration, subtle bubbles and dense fluid clusters. No existing game's chemical texture imitation.
```
## Prompt 09 — Ácido
```text
Create an original 16×16 pixel-art fictional acid liquid texture for NEXORA. Toxic-looking green-yellow fluid with small reactive pixel clusters and restrained glow cues. Original design only.
```
## Prompt 10 — Fluido criogênico
```text
Create an original 16×16 pixel-art cryogenic fluid texture for NEXORA. Pale blue translucent-looking liquid with cold sparkling pixel clusters and smooth flow cues. Invent the pattern from scratch.
```
## Prompt 11 — Fluido médico
```text
Create an original 16×16 pixel-art fictional medical fluid texture for NEXORA. Clean translucent liquid with subtle cool or warm tint and sterile visual language. No copied game potion texture.
```
## Prompt 12 — Fluido energético
```text
Create an original 16×16 pixel-art condensed energy liquid texture for NEXORA. Abstract fluid appearance expressed through compact luminous pixel clusters in a controlled fictional palette. No copied sci-fi game energy texture.
```
## Prompt 13 — Fluido mágico
```text
Create an original 16×16 pixel-art magical liquid texture for NEXORA. Fictional translucent fluid with restrained luminous particles and original color relationships. No copied fantasy-game liquid.
```
## Prompt 14 — Fluido dimensional
```text
Create an original 16×16 pixel-art dimensional liquid texture for NEXORA. Dark translucent fluid with subtle impossible color shifts and fractured flow patterns. Completely original pixel arrangement.
```
## Prompt 15 — Fluido espacial
```text
Create an original 16×16 pixel-art extraterrestrial liquid for NEXORA. Strange but believable fictional chemistry, controlled deep colors and sparse mineral-like reflections. No copying existing games.
```
## Prompt 16 — Fluido industrial pesado
```text
Create an original 16×16 pixel-art heavy industrial fluid for NEXORA. Thick dark liquid with dense clusters, subtle metallic reflections and slow-flow visual cues. Invent the pattern independently.
```

## Expansão para 80
Usar o mesmo padrão de famílias para completar 80 líquidos: naturais, minerais, combustíveis, industriais, químicos, médicos, criogênicos, energéticos, mágicos, dimensionais, espaciais e especiais NEXORA. Cada entrada final deve receber nome, paleta, densidade e prompt concreto antes da geração.
