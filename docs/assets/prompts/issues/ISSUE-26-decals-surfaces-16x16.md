# NEXORA — DECALS E SUPERFÍCIES ESPECIAIS / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar.

## Prompt 01 — Faixa de Segurança
```text
Create an original 16×16 pixel-art fictional safety stripe decal for the NEXORA game. Use strong geometric bands, limited high-contrast palette and a completely invented marking language. Designed to overlay voxel floors and machinery. Do not reproduce real industrial warning graphics or existing game decals. No text, logo or watermark.
```
## Prompt 02 — Marcação de Piso
```text
Create an original 16×16 pixel-art fictional floor marking for NEXORA. Use a simple geometric symbol or path indicator with strong readability and controlled wear. Invent the symbol and pixel arrangement from scratch. Do not copy real road markings or existing game graphics. No text, logos or watermark.
```
## Prompt 03 — Símbolo Técnico
```text
Create an original 16×16 pixel-art technical symbol for NEXORA. Minimal geometric design, high semantic readability and restrained palette, suitable for machines and facilities. Invent a unique symbol. Do not imitate existing game interfaces, logos or industrial marks. No text or watermark.
```
## Prompt 04 — Padrão Industrial
```text
Create an original 16×16 pixel-art industrial surface pattern for NEXORA. Modular geometric arrangement, practical engineering appearance and controlled wear. Designed as a reusable decal or overlay. Invent a new pattern without copying existing game assets or real brands.
```
## Prompt 05 — Alerta Gráfico
```text
Create an original 16×16 pixel-art fictional hazard pictogram for NEXORA. Strong silhouette, simple geometric warning language and limited palette. Do not reproduce any real-world hazard logo or existing game's warning sign. No readable text, logo or watermark.
```
## Prompt 06 — Sujeira Localizada
```text
Create an original 16×16 pixel-art grime decal for NEXORA. Irregular darkened patches, subtle tonal variation and compact organic/industrial wear. Designed as an overlay with transparent-ready background. Invent the exact pattern; do not copy existing game textures.
```
## Prompt 07 — Ferrugem Localizada
```text
Create an original 16×16 pixel-art rust decal for NEXORA. Irregular orange-brown oxidation clusters spreading over a neutral surface, with natural asymmetry and crisp pixels. Transparent-ready overlay. Completely original pattern; no copied game wear texture.
```
## Prompt 08 — Arranhões
```text
Create an original 16×16 pixel-art scratch decal for NEXORA. Several controlled directional scratches represented by crisp pixel strokes, transparent-ready and suitable for vehicles, machines and structures. Invent all marks independently. Do not imitate existing game damage overlays.
```
## Prompt 09 — Desgaste
```text
Create an original 16×16 pixel-art material-wear decal for NEXORA. Edge wear, faded patches and compact abrasion patterns, transparent-ready for layered materials. Original pixel placement only. No copied game texture or recognizable third-party design.
```
## Prompt 10 — Mancha
```text
Create an original 16×16 pixel-art stain decal for NEXORA. Irregular localized discoloration with subtle color variation and transparent-ready background. Suitable for industrial, natural and historical surfaces. Invent a new pattern and do not copy existing game decals.
```
## Prompt 11 — Marca de Uso
```text
Create an original 16×16 pixel-art usage-mark decal for NEXORA. Repeated-contact wear, small dents or faded touch zones represented with simple readable pixel clusters. Transparent-ready. Create a unique pattern without copying any existing game asset.
```
## Prompt 12 — Laboratório/Fábrica Especial
```text
Create an original 16×16 pixel-art technical surface decal for a fictional NEXORA laboratory or factory. Use modular geometric marks, controlled wear and an invented visual language. No readable text, no real-world branding, no copied game pattern, no watermark.
```

## Aceitação
- [ ] 16×16
- [ ] transparent-ready quando necessário
- [ ] símbolos originais
- [ ] variantes de desgaste coerentes
- [ ] integração em superfícies validada
- [ ] proveniência registrada
