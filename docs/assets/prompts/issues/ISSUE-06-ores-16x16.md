# NEXORA — MINÉRIOS 16×16 / PROMPTS PRONTOS

Todos os prompts são prontos para copiar/colar. Para os 48 minérios, use uma família mineral por prompt e mantenha a identidade NEXORA.

## Prompt-base individual
```text
Create an original 16×16 pixel-art ore texture for the NEXORA voxel game.
Use the ore and host-rock concept described below only as geological inspiration. Invent the exact pixel clusters, ore distribution, colors, shapes and surface pattern from scratch.
The texture must be readable at tiny resolution, suitable for voxel mining, and visually consistent with the NEXORA material language.
Do not copy, trace, reconstruct or closely imitate any existing game's ore texture, pixel arrangement or palette structure.
Ore: [ORE NAME]
Host rock: [HOST ROCK]
Ore color: [ORE COLOR]
Abundance: [LOW / MEDIUM / HIGH / VERY RARE]
No text, logo, watermark, perspective or scenery.
```
