# NEXORA — VEÍCULOS E TRANSPORTES / PROMPTS PRONTOS

Todos os prompts são independentes e prontos para copiar/colar. A meta é criar materiais modulares, não modelos completos.

## Prompt 01 — Carroceria Terrestre
```text
Create an original 16×16 pixel-art vehicle body material for the NEXORA voxel game. Rugged engineered paneling, subtle seams, controlled wear and a distinctive fictional industrial palette. Designed for modular land vehicles. Invent every pixel arrangement from scratch. Do not copy or closely imitate any existing game's vehicle texture, livery, logo or model surface. No text, watermark or scenery.
```
## Prompt 02 — Blindagem
```text
Create an original 16×16 pixel-art armored vehicle material for NEXORA. Dense protective alloy, layered plates, subtle impact wear and restrained highlights. Functional and modular. Completely original pixel pattern; do not reproduce any existing game armor or vehicle texture. No text, logo or watermark.
```
## Prompt 03 — Veículo Aéreo
```text
Create an original 16×16 pixel-art aircraft body material for NEXORA. Lightweight composite panels, rivet hints, controlled wear and a coherent fictional aerospace palette. Designed for modular aircraft surfaces. No copied livery, logo, game texture or real-world branding.
```
## Prompt 04 — Veículo Naval
```text
Create an original 16×16 pixel-art naval vessel material for NEXORA. Weathered marine alloy, painted structural panels, salt wear and restrained oxidation. Suitable for ships and modular naval structures. Invent the pixel arrangement independently. No copied game asset, text, logo or watermark.
```
## Prompt 05 — Trem
```text
Create an original 16×16 pixel-art train exterior material for NEXORA. Heavy rail alloy, layered painted panels, subtle grime and mechanical wear. Designed for repeated modular train sections. Do not imitate any existing game's train texture or livery. No text, logo or watermark.
```
## Prompt 06 — Vagão
```text
Create an original 16×16 pixel-art freight wagon material for NEXORA. Industrial sheet metal, reinforced edges, weathered paint and compact structural details. Repeatable and readable. Invent a unique surface pattern without copying any game or real-world branded wagon.
```
## Prompt 07 — Veículo Industrial
```text
Create an original 16×16 pixel-art heavy industrial vehicle material for NEXORA. Thick alloy panels, work grime, reinforced joints and a practical fictional industrial palette. Suitable for loaders, haulers and factory transport. No copied game vehicle texture, logo or livery.
```
## Prompt 08 — Veículo de Exploração
```text
Create an original 16×16 pixel-art exploration vehicle surface for NEXORA. Durable composite panels, field wear, modular equipment mounts and subdued expedition colors. Original design and pixel arrangement only. No imitation of existing game or real-world vehicle designs.
```
## Prompt 09 — Veículo Espacial
```text
Create an original 16×16 pixel-art spacecraft exterior material for NEXORA. Advanced fictional alloy, panel segmentation, thermal wear and subtle technological cues. Designed for modular orbital craft. Invent all surface patterns independently. Do not copy existing science-fiction game textures or spacecraft liveries. No text or logo.
```
## Prompt 10 — Estação
```text
Create an original 16×16 pixel-art orbital or transit station exterior material for NEXORA. Large modular engineered panels, maintenance wear and restrained advanced-tech details. Designed to repeat across massive structures. No copied game station texture, logo, text or watermark.
```
## Prompt 11 — Componente Externo
```text
Create an original 16×16 pixel-art vehicle external component material for NEXORA. Fictional mechanical housing with metal, composite and rubber zones, designed for modular engines, mounts and machinery. New pixel arrangement only; no copied existing game asset.
```
## Prompt 12 — Vidro de Veículo
```text
Create an original 16×16 pixel-art vehicle glass material for NEXORA. Dark tinted translucent-looking surface, subtle reflective pixel grouping and clean frame-compatible edges. Invent the pattern from scratch. Do not imitate any existing game's vehicle glass or interface. No text, logo or watermark.
```
## Prompt 13 — Painel de Veículo
```text
Create an original 16×16 pixel-art vehicle control-panel material for NEXORA. Compact fictional indicators, switches and technical divisions represented through simple abstract pixels. No readable text and no real-world branding. Completely original interface arrangement.
```
