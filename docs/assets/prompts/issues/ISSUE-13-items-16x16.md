# NEXORA — ITENS 16×16 / PROMPTS PRONTOS

## Objetivo
Catalogar e produzir até **2.500 tipos de itens**, usando 16×16 como base para ícones/texturas simples.

Os prompts abaixo são prontos para copiar. Para cada item concreto do catálogo, preencher somente o nome e família indicados no próprio registro. Não criar duplicatas de assets que já existem no NEXORA.

## Prompt-base pronto
```text
Create an original 16×16 pixel-art item icon or simple item texture for the NEXORA game.
Make the function and material immediately readable at tiny resolution using a strong silhouette, controlled pixel clusters, restrained palette and consistent NEXORA visual language.
Invent the exact shape, pixel arrangement, palette relationship and surface details from scratch.
Do not copy, trace, reconstruct or closely imitate any existing game's item, icon, texture, logo, symbol or visual design.
Item family: [FAMILY]
Item name: [ITEM]
Material: [MATERIAL]
Function: [FUNCTION]
Variant: [VARIANT]
Palette mood: [PALETTE]
No text, watermark, third-party logo, copied symbol, perspective or environment.
Output exactly one 16×16 square asset.
```

## Prompts prontos por família

### Prompt — Recurso bruto
```text
Create an original 16×16 pixel-art raw resource icon for NEXORA. Compact irregular material cluster, clear mineral/organic identity, restrained palette and strong silhouette. Invent the exact pixel pattern from scratch. Do not imitate any existing game's resource icon or texture. No text, logo or watermark.
```

### Prompt — Material processado
```text
Create an original 16×16 pixel-art processed material icon for NEXORA. Clear manufactured shape, readable material identity and compact pixel detailing. Invent a completely new arrangement. No copied game asset, text, logo or watermark.
```

### Prompt — Componente industrial
```text
Create an original 16×16 pixel-art industrial component icon for NEXORA. Functional mechanical or electronic form, strong silhouette, controlled highlights and subtle wear. Completely original design. No existing game imitation.
```

### Prompt — Ferramenta
```text
Create an original 16×16 pixel-art tool icon for NEXORA. Distinctive functional head, durable handle or housing, strong silhouette and readable material separation. Invent the object independently. Do not copy existing game tools or icons. No text, logo or watermark.
```

### Prompt — Consumível
```text
Create an original 16×16 pixel-art consumable item icon for NEXORA. Compact recognizable silhouette, clear material/function cues and restrained palette. Invent a unique design without imitating existing games. No text, logo or watermark.
```

### Prompt — Alimento
```text
Create an original 16×16 pixel-art food item for NEXORA. Invent a fictional or generic edible form with clear silhouette, memorable color grouping and restrained highlights. Do not reproduce recognizable existing game food designs. No text or watermark.
```

### Prompt — Equipamento
```text
Create an original 16×16 pixel-art equipment item icon for NEXORA. Compact functional silhouette, layered materials and strong low-resolution readability. Check existing NEXORA equipment before generation to avoid duplication. No copied game asset, text or logo.
```

### Prompt — Artefato
```text
Create an original 16×16 pixel-art fictional artifact icon for NEXORA. Memorable compact silhouette, unusual material combination and restrained special details. Invent everything from scratch. Do not imitate existing fantasy or science-fiction game artifacts.
```

### Prompt — Componente científico
```text
Create an original 16×16 pixel-art scientific component icon for NEXORA. Fictional instrument part, sensor or laboratory component with simple technical geometry and strong silhouette. Original design only. No copied interface, brand, text or game asset.
```

### Prompt — Item histórico
```text
Create an original 16×16 pixel-art historical item icon for NEXORA. Aged fictional object with clear material identity and subtle wear. It must feel like part of an original world history, not a real artifact reproduction. No text, logo or watermark.
```

### Prompt — Item mágico
```text
Create an original 16×16 pixel-art magical item icon for NEXORA. Fictional object with controlled energy cues, memorable silhouette and restrained luminous pixels. Invent the visual identity completely. Do not imitate existing fantasy-game items.
```

### Prompt — Item dimensional
```text
Create an original 16×16 pixel-art dimensional item icon for NEXORA. Compact object with unusual geometry and controlled impossible-material cues. Completely new pixel arrangement. No copied game asset, symbols or logos.
```

### Prompt — Item espacial
```text
Create an original 16×16 pixel-art advanced space item icon for NEXORA. Fictional engineered object, compact silhouette, subtle advanced materials and clean pixel structure. Do not copy existing science-fiction game items or interfaces.
```

## Organização dos 2.500 itens
Distribuir por famílias antes da geração: recursos, materiais, ferramentas, componentes, construção, indústria, agricultura, alimentos, exploração, ciência, medicina, energia, transporte, equipamentos, artefatos, história, magia, dimensões, espaço e itens especiais.

Itens que já possuem assets próprios no NEXORA devem ser marcados como **existentes** e não recriados automaticamente. Armaduras, armas, escudos e mesas de trabalho já existentes têm prioridade de preservação.
