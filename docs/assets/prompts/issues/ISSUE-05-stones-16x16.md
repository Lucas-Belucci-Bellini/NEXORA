# NEXORA — PEDRAS 16×16 / PROMPTS PRONTOS

Cada prompt abaixo pode ser copiado diretamente para geração. Todos exigem **16×16**, design original e uso adequado em construção voxel.

## Prompt 01 — Granito claro
```text
Create an original 16×16 pixel-art light granite texture for the NEXORA voxel game. Use a pale mineral base with irregular interlocking grains, subtle warm and cool inclusions, medium contrast and a construction-friendly repeat. Invent every pixel cluster from scratch. Do not copy or imitate any existing game's stone texture. No text, logo, watermark, perspective or scenery.
```
## Prompt 02 — Granito escuro
```text
Create an original 16×16 pixel-art dark granite texture for NEXORA. Dense charcoal-gray mineral base, irregular lighter grains, controlled contrast and natural stone variation. Create a completely new pixel arrangement. Do not reproduce any existing game texture or pattern. No text, logo, watermark or environment.
```
## Prompt 03 — Calcário
```text
Create an original 16×16 pixel-art limestone texture for NEXORA. Pale sedimentary stone with soft mineral variation, subtle pores and faint fossil-like abstract marks. Keep it readable and repeatable. Invent the pixel structure independently. Do not imitate existing game blocks. No text, logo or watermark.
```
## Prompt 04 — Arenito rochoso
```text
Create an original 16×16 pixel-art rocky sandstone texture for NEXORA. Layered sandy mineral bands, rough grain and muted warm tones. Designed for walls and foundations. Original pixel clusters only; do not copy any existing game's sandstone texture. No text, logo, watermark or scenery.
```
## Prompt 05 — Ardósia
```text
Create an original 16×16 pixel-art slate texture for NEXORA. Dark layered stone with thin planar divisions, cool gray tones and restrained irregular fractures. Create a new low-resolution pattern. No copied game texture, text, logo or watermark.
```
## Prompt 06 — Basalto
```text
Create an original 16×16 pixel-art basalt construction texture for NEXORA. Dense dark volcanic rock with compact mineral clusters, subtle charcoal variation and occasional lighter inclusions. Rich enough for large constructions but calm enough to tile. Invent all pixel placement from scratch. Do not copy, trace or closely imitate any existing game's basalt texture. No text, logo, watermark, perspective or scenery.
```

