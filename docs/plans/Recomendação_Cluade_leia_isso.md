Eu chamaria de:

`docs/plans/`

É o nome mais simples, profissional e fácil de entender.

Dentro dela, você pode separar assim:

```text
docs/
└── plans/
    ├── architecture/
    ├── engineering/
    ├── systems/
    ├── gameplay/
    ├── content/
    ├── assets/
    ├── ai/
    ├── networking/
    ├── modding/
    ├── tooling/
    └── roadmap/
```

E eu **não colocaria os relatórios de execução nessa pasta**. Manteria separado:

```text
docs/
├── plans/
└── autonomous-reports/
```

Assim fica muito claro:

**`plans/` = o que pretendemos construir.**
**`autonomous-reports/` = o que realmente foi feito em cada execução.**

Para o NEXORA, `docs/plans/` é minha recomendação principal.
