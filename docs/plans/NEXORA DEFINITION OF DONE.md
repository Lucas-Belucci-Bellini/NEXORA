# NEXORA — DEFINITION OF DONE

Um trabalho só é considerado concluído quando o nível apropriado de engenharia foi atendido.

## Sistema arquitetural

```text
responsibility
non-responsibilities
ownership
state model
API
commands/events/queries
threading
memory
persistence
network
security
LOD
mod/script boundary
observability
tests
vertical slice
```

## Código

```text
builds
lint/static analysis
unit/integration tests
error handling
logging/diagnostics
documentation
```

## Conteúdo

```text
valid assets
references resolved
IDs stable
license/provenance recorded
performance budget checked
```

## Release candidate

```text
CI green
save compatibility tested
smoke tested
artifacts generated
checksums recorded
known issues documented
```

Não considerar “funciona na minha máquina” como Definition of Done.
