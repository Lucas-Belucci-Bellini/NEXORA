# NEXORA — Production prompt 58: Caves & Underground Props

## Mission
Create original, production-ready NEXORA assets for **Caves & Underground Props**, isolated to this prompt folder.

## Scope
Elementos ambientais e equipamentos para cavernas, túneis e áreas subterrâneas.

## Required asset families
1. estalactites e estalagmites
2. cristais minerais naturais
3. fungos subterrâneos
4. marcadores de trilha
5. escoras de túnel
6. lanternas e balizas
7. depósitos de sedimentos
8. acampamentos subterrâneos compactos

## Pre-generation checklist
Read this prompt and relevant art-direction/pipeline documentation. Inspect repository assets and manifests, then list missing assets, variants, IDs, counts, and dimensions. Avoid duplicates; source issue requirements take precedence.

## Image-generation protocol
- Create original NEXORA designs. Never copy, trace, extract, or closely reconstruct third-party game assets, mods, brands, or artwork.
- Determine whether each output is a texture, tileable material, icon, sprite, or isolated prop.
- Follow exact pipeline dimensions; a required 16×16 texture must be natively 16×16 pixels.
- Preserve coherent voxel/pixel-art style, readable silhouettes, controlled pixel clusters, deliberate palettes, and clear material separation.
- Avoid accidental blur, unwanted anti-aliasing, photorealism, unrelated scenery, watermark, logo, and unrequested text. Use transparency only when appropriate.
- Tileable textures must pass a repeated 3×3 seam check. Isolate props and keep framing consistent.
- Inspect at native size and enlarged nearest-neighbor scale. Validate dimensions, format, transparency, readability, silhouette, duplicate risk, naming, and source requirements; regenerate failures.
- Contact sheets are previews only and never replace individual production files.
- Record only verifiable metadata, using `unknown` when unavailable. Never claim generation, saving, inspection, or validation without the actual file and completed check.

## Output contract
Save final images only in `assets/generated/prompts/prompt-58-caves/images/`. Use stable lowercase filenames. Maintain `manifest.json` in that folder with asset ID, filename, source prompt, tool/model/date when known, dimensions, format, version, status, originality review, and validation results. Version approved assets rather than overwriting them.

## Completion report
Report requested/generated/accepted/rejected counts, exact paths, validation performed, missing requirements, and blockers. Distinguish verified facts from recommendations.
