# Images — Prompt 43: Library & Knowledge Props

This directory is reserved exclusively for outputs from `../PROMPT.md`.

## Rules
- Save only assets belonging to prompt 43 here.
- Keep final assets separate from previews/contact sheets.
- Use stable lowercase filenames and preserve each asset's ID.
- Do not overwrite an approved image without creating a versioned revision.
- Create/update `manifest.json` with asset metadata and validation results.
- Verify the actual file before marking an asset as generated or accepted.
- Do not save images from another prompt here.
