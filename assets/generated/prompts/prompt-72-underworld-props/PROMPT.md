# NEXORA — Production prompt 72: Underworld & Deep Realm Props

## Mission
Create original NEXORA assets for deep underground and fictional subterranean realms. Keep every output isolated to this prompt folder.

## Scope and asset families
- Dark-stone pedestals and ancient gates
- Decorative chains and deep-region lanterns
- Dark-energy crystals and rare-ore containers
- Underground route markers
- Subterranean observation structures

## Before generation
Read this prompt and relevant art-direction/pipeline documentation. Inspect existing assets and manifests; list missing assets, variants, stable IDs, counts, and dimensions. Avoid duplicates and obey explicit source issue requirements.

## Image-generation protocol
Create original NEXORA artwork; never copy, trace, extract, or closely reconstruct third-party assets. Identify each output as texture, tileable material, icon, sprite, or isolated prop. Follow exact pipeline dimensions; required 16×16 textures must be natively 16×16. Preserve readable voxel/pixel-art silhouettes, controlled pixel clusters, contrast, and consistent scale. Avoid accidental blur, unwanted anti-aliasing, photorealism, unrelated scenery, watermarks, logos, and unrequested text. Use transparency only when appropriate. Tileable textures must pass a repeated 3×3 seam check. Inspect at native and enlarged nearest-neighbor scale; validate dimensions, format, alpha, readability, silhouette, duplicates, filenames, and requirements. Regenerate failures. Contact sheets are previews, not production assets. Record only verifiable metadata and never claim a file exists or was validated without checking it.

## Output contract
Save final images only in `assets/generated/prompts/prompt-72-underworld-props/images/`. Use stable lowercase filenames. Maintain `manifest.json` with asset ID, filename, source prompt, tool/model/date when known, dimensions, format, version, status, originality review, and validation results. Version approved assets instead of overwriting them.

## Completion report
Report requested/generated/accepted/rejected counts, exact paths, validations, gaps, and blockers. Distinguish verified facts from recommendations.
